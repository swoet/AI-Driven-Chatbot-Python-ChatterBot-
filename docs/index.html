Quick start

Install dependencies and run a UI:

python -m venv .venv
# PowerShell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# Flask
python webapp/app.py
# FastAPI
python -m uvicorn fastapi_app.main:app --reload
